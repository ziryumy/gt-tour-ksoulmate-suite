# 채널별 나레이션 재창작 규칙

**핵심**: 번역이 아니다. 같은 사건을 각 언어의 말투로 다시 쓴다.
**자막과 나레이션은 다른 층이다.** 자막은 한국어 대사 원음의 번역이고, 나레이션은 그 위에 새로 얹는 별개 창작물이다. 둘은 공존한다.

---

## 1. 4채널 화법 규칙

### JP — 하루토, 일기체 (90초 / 24컷 / 평균 3.8초)
- **금지**: 감탄사(すごい！), 과장된 형용사, 설명하는 문장
- **필수**: 1인칭, 과거형 회상, 신체 감각(손·숨·목소리)
- 문장 사이 0.8~1.2초 여백. 마지막 두 줄은 속삭이듯
- 작업 순서: 대본 → V.O. → 컷 → BGM

### US — 이든 박, 비트체 (60초 / 32컷 / 평균 1.9초)
- **금지**: 문어체, 긴 문장, 조용한 톤
- **필수**: 현재형, 감탄, 시청자에게 말 거는 호흡("watch this"), 강조어
- 컷 전환을 하이햇에 동기. 임팩트 단어는 드롭에
- 작업 순서: BGM → 비트 마커 → 컷 → V.O.

### KR — 지후, 담백체 (90초 / 18컷 / 평균 5.0초)
- **금지**: 과장, 감성적 수사
- **필수**: 오늘의 표현 명시, 장소명, 다음 화 예고
- 한 컷 5초 이상 유지해 자막을 읽게
- 작업 순서: 자막 → 컷 → V.O. → BGM

### CN — 린위하오, 감성체 (88초 / 22컷 / 평균 4.0초)
- 감성적이되 짧게 끊는다. 화면 하단에 자막 영역을 비운다
- **중국어 자막은 번역이 아니라 1차 창작.** 일본어 대본을 옮기지 말고 중국어로 새로 쓴다
- 작업 순서: 자막 → 컷 → V.O. → BGM

## 2. 1화 씬6 실례 — 같은 장면, 세 가지 나레이션

**원본 장면 (4채널 공통)**: 하루토가 카운터로 걸어간다. 손이 조금 떨린다. 혼자 한국어로 주문한다. 바리스타가 "얼음 적게요, 네"라고 답한다. 2초 정적. 컵을 받는다.

### JP
```
오늘, 처음으로 혼자 주문했어요.
형은 밖에 나가 있었어요. 저 혼자였어요.
카운터까지 걸어가는 동안, 손이 조금 떨렸어요.
「얼음은 적게 넣어 주세요」
연습한 그 문장이, 제 입에서 나왔어요.
컵을 받았을 때 —
아, 왠지 조금 자랑스러웠어요.
형은 밖에서 웃고 있었어요.
```
- 여백: 각 문장 0.8~1.2초, 5번째 줄 뒤 2.0초
- BGM: 어쿠스틱 피아노 68 BPM. 4번째 줄에서 피아노 멎음
- 사운드: "됐어요" 직후 2초 완전 무음 — 숨소리만
- 마지막 줄: 속삭임. 자막 띄우지 않음

### US
```
Okay so — watch this.
Hyung dips. Leaves him ALONE.
Just him, the counter, and pure pressure.
Barista's like "... you good?"
And he says it. Clean.
「얼음은 적게」— ICE. LESS.
Man said it PERFECT. First try. No help.
Okay okay okay. That's my boy.
```
- BGM: 붐뱁 96 BPM. 첫 비트에 첫 컷
- 동기: 컷 전환 전부 하이햇 동기. 'PERFECT'는 드롭에 임팩트
- 자막: 강조 단어만 대형. 문장 전체 자막 금지

### KR
```
혼자 주문에 성공했습니다.
오늘 배운 표현은 「얼음은 적게 넣어 주세요」입니다.
성수동 ○○카페에서 실제로 통하는 문장입니다.
다음 화는 편의점입니다. 훨씬 어렵습니다.
```
- BGM: 밝은 로파이 85 BPM, 보컬 없음
- 자막: 장소 정보 하단 고정, 협력 매장 계정 태그

## 3. 판정 기준

세 대본은 **서로 번역 관계가 아니어야 한다.** 검수 시 확인할 것:

- [ ] JP와 US를 나란히 놓았을 때 문장이 1:1 대응하지 않는가
- [ ] US가 JP보다 정보량이 많고 컷이 빠른가 (그게 정상)
- [ ] KR이 가장 짧은가 (정보만 남기므로)
- [ ] 어떤 대본에도 번역투("~라고 말했다", "그것은 ~이다")가 없는가

---

## 4. 앱에서의 취급

`ChannelVersion.narration` 필드는 **채널별로 완전히 독립**이다.
번역 자동화를 넣지 말 것. 재창작은 자동화 대상이 아니다.
편집 화면 상단에 해당 채널의 화법 규칙(`channel.tone` + 금지/필수)을 항상 표시한다.
