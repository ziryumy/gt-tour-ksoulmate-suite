# 베이스 영상 생성 규격 — 헤드룸

## 왜 필요한가

채널마다 길이와 컷 수가 다르다. JP는 90초·24컷, US는 60초·32컷.
**같은 재료로 두 버전을 만들려면 가장 긴 채널보다 넉넉하게 생성해야 한다.**

60초판에서 버린 컷을 90초판이 다시 쓴다. 반대는 불가능하다.
컷을 짧게 만들어두면 어떤 편집으로도 늘릴 수 없다.

---

## 규격

| 항목 | 값 |
|---|---|
| 완성 목표 | 90초 |
| **생성 길이** | **약 130초 분량** |
| 고유 컷 (숏폼 1본) | 44 |
| 실제 생성 횟수 | 61 (채택률 75% + 재생성 2회) |
| 컷 앞뒤 핸들 | 각 0.5초 |
| 세로 렌더 | 9:16 별도 |
| 무음 마스터 | 반드시 보관 (V.O.·BGM 얹기 전) |

| 순위 | 사유 | 대응 |
|---|---|---|
| 1 | 얼굴 불일치 | 레퍼런스 시트 매 생성 고정 입력 / Soul ID |

| 3 | 암소·풀샷 붕괴 | 낮은 해상도로 먼저 구도 확인 |

## 크레딧 계산

```
편당 생성 = 고유컷 ÷ 0.75 + 재생성
숏폼:   44 ÷ 0.75 ≈ 59 + 2 = 61
참여형: 12 ÷ 0.75 ≈ 16 + 2 = 18
장편:   70 ÷ 0.75 ≈ 94 + 6 = 100
```

월 416회 → 약 9,400 크레딧 → $310

**주의**: Higgsfield 공식 블로그는 Seedance 2.5에서 클립 1개당 3~5회 시도가 필요하고
30클립 기준 월 $324~540이 소모된다고 밝히고 있다. 위 계산의 3~4배다.
**첫 4주는 Ultra 하나로 실측**하고 시나리오를 확정한다.

## 절감 순서

1. 채택률 올리기 (75% → 85%면 생성량 12% 감소) — 가장 확실
2. Soul ID로 일관성 고정 → 얼굴 불일치 재생성 제거
3. 검수는 720p, 채택된 컷만 1080p
4. 남은 크레딧은 그 달에 몰아서 사용 (이월 없음)
