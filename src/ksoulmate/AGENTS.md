## 0. 한 줄 정의

**K-soulmate 콘텐츠 운영 콘솔** — 5인조 AI 아이돌 콘텐츠를 12화 × 4채널로 재조립·검수·발행하는 내부 운영 도구.
공개 서비스가 아니라 **팀 내부 도구**입니다.

## 2. 절대 하지 말 것

1. **드래그 앤 드롭으로 단계를 옮기게 만들지 말 것.**
   모든 단계 이동은 **버튼(이전/다음) 또는 단계 드롭다운**입니다. 사용자가 명시적으로 요구한 사항입니다.
2. **AI 생성 API를 호출하지 말 것.** 이 앱은 Higgsfield/Claude를 "기록"하는 도구입니다. 생성은 외부에서 합니다.
3. **도메인 데이터를 창작하지 말 것.** 모든 시드 데이터는 `data/*.json`에서 옵니다. 12화, 5인, 채널 규격, 예산은 지어내면 안 됩니다.
4. **결제·로그인·공개 페이지를 만들지 말 것.** Phase 1 비목표입니다.
5. **UI 문구를 영어로 쓰지 말 것.** 화면에 보이는 모든 텍스트는 한국어입니다. (코드 식별자·변수명은 영어)
6. **숫자를 반올림하거나 예쁘게 바꾸지 말 것.** 15.7시간은 16시간이 아니고, $350은 $300이 아닙니다.

- 화면 텍스트 · 라벨 · 에러 메시지 · 빈 상태 문구: **한국어**

- 커밋 메시지: 한국어 허용

- 통화: 크레딧·달러는 `$`와 소수 없이, 원화는 `만 원` 단위

## 5. 작업 순서 (지키세요)

에이전트는 아래 순서를 **건너뛰지 않습니다.** 한 단계가 통과해야 다음으로 갑니다.

1. **M1 — 스캐폴드 + 데이터층**
   Next.js 생성 → Prisma 스키마 → `npx prisma migrate dev` → `seed.ts`로 `data/*.json` 전부 적재 → `/dashboard`에 총 건수만 표시.
   통과 조건: `members` 5건, `episodes` 12건, `channels` 4건이 DB에서 조회됨.

2. **M2 — 조회 화면 3개**
   `/members`, `/episodes`, `/episodes/[no]`. 읽기 전용.
   통과 조건: 12화 목록이 담당·표현과 함께 보이고, 1화 클릭 시 채널 4개 탭이 뜸.

3. **M3 — 쓰기 + 규칙 엔진**
   단계 이동(버튼/드롭다운), 채널 버전 편집, 길이 규격 검증, 크레딧 기록.
   통과 조건: `SPEC.md` AC-01 ~ AC-09 전부.

4. **M4 — 게이트 + 참여**
   컴플라이언스 차단, 응원 게이지, 팬덤명 후보, 미션 회수.
   통과 조건: AC-10 ~ AC-14.
