# K-soulmate 콘텐츠 운영 콘솔 — 인수인계 키트

이 폴더는 이 대화에서 확정된 기획을 **바로 코딩할 수 있는 형태**로 정리한 것입니다.
Antigravity(또는 다른 에이전트형 IDE)에 이 폴더를 열어주고, `HANDOFF-PROMPT.md`의 순서대로 지시하면 됩니다.

---

## 1. 무엇을 만드는가

**K-soulmate 콘텐츠 운영 콘솔** — 5인조 AI 아이돌 콘텐츠를 매주 3채널로 재조립해 내보내는 내부 운영 도구.

| 기능 | 왜 필요한가 |
|---|---|
| 캐릭터 락 레지스트리 | 영상마다 얼굴이 달라지면 시리즈가 성립하지 않음 |
| 에피소드 보드 (12화) | 5인 × 12화 × 4채널 = 최대 240개 버전을 손으로 관리할 수 없음 |
| 채널 재조립 트래커 | 같은 화면에 채널별로 대본·BGM·컷수가 전부 다름 |
| 크레딧·예산 | 생성 크레딧은 이월되지 않고, 리트라이 배수가 3~4배까지 벌어짐 |
| 컴플라이언스 게이트 | 3·6·7화는 약기법 대상. 공개 전 차단이 필요 |
| 참여 관리 | 팬덤명 공모·응원 게이지·미션 회수 |

**만들지 않는 것 (Phase 1 비목표)**
- AI 생성 API 직접 호출 (이 앱은 **기록**하지, 생성하지 않습니다)
- 결제·회원가입·공개 팬페이지 (Phase 2, 법무 선행 필요)
- 실제 영상 렌더링

## 2. 폴더 구성

```
AGENTS.md              ← 코딩 에이전트가 가장 먼저 읽는 규칙. 반드시 루트에 둘 것
SPEC.md                ← 제품 스펙 + 수용 기준(AC). 여기가 본문
DECISIONS.md           ← 확정된 것 / 아직 안 정한 것
HANDOFF-PROMPT.md      ← Antigravity에 순서대로 붙여넣을 3단계 프롬프트
data/
  members.json         ← 5인 캐릭터 락 (실사 시트 URL 포함)
  channels.json        ← 4채널 규격 (컷수·길이·BGM·작업순서)
  episodes.json        ← 시즌1 12화
  budget.json          ← 요금제·크레딧·월 예산
  kpis.json            ← 90일 / 12개월 목표
  compliance.json      ← 일본 시장 7개 항목
prompts/
  character-photoreal.md   ← 실사 캐릭터 시트 생성 프롬프트 (검증됨)
  character-anime.md       ← 애니 캐릭터 시트 프롬프트 (검증 결과 포함)
  localization-narration.md ← 채널별 나레이션 3종 규칙 + 1화 실례
  base-video-headroom.md   ← 베이스 영상 생성 규격
```

---

## 3. 쓰는 순서 (약 30분 + 코딩 시간)

1. **폴더를 새 저장소 루트에 복사**하고 `AGENTS.md`가 루트에 있는지 확인
2. Antigravity를 열고 `HANDOFF-PROMPT.md`의 **1단계**를 붙여넣기
3. 결과 확인 후 **2단계**, 그다음 **3단계**
4. 매 단계 끝에서 `SPEC.md` 6장의 수용 기준으로 자체 검증을 시키기

> 한 번에 전부 시키지 마세요. 에이전트형 IDE는 단계가 길어질수록 앞의 결정을 잊습니다.

---

## 4. 이 키트에 들어 있는 것 / 없는 것

**들어 있는 것**
- 이 대화에서 확정된 모든 수치 (공수 15.7h, 월 $350, 크레딧 61/18/100, 채널 규격, KPI)
- 5인 캐릭터 정의 + 실사 시트 이미지 URL
- 12화 구성 + 담당 + 오늘의 표현
- 채널별 나레이션 실제 대본 3종 (1화 씬6)
- 일본 시장 법규 7항목

**들어 있지 않은 것 (의도적)**
- 결제·법무 문서 원문 (전문가 검토 필요)
- 실제 영상 파일 (Higgsfield에서 별도 생성)
- 애니메이션 시트 5장 (하루토 1장만 테스트 완료, 판정 3/5 — `DECISIONS.md` 참조)
